      # boolean

      返回布尔值的运算符：

      • 前置逻辑运算符： ! (Not)

      • 相等运算符：===，!==，==，!=

      • 比较运算符：>，>=，<，<=

      条件判读自动转为false的值：

      • undefined

      • null

      • false

      • 0

      • NaN

      • '' "" (空字符串)

      if ('') {
  console.log('true');
}
// 没有任何输出

if ([]) {
  console.log('true');
}
// true

if ({}) {
  console.log('true');
}
// true
