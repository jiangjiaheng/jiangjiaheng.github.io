              # 认知模型

              这个页面整合原来的“量子启示”“无限变量”“想象力”等短笔记。

              它关注的不是科学解释本身，而是这些概念给个人认知带来的启发。

              # 1. 世界不是连续的

              量子论给我的启发是：现实并不总是连续、平滑、线性的。

              很多时候，我们以为一件事可以无限细分、无限控制、无限优化，但现实并不是这样。

              现实中更常见的是：

              • 状态会跳变
              • 情绪会断裂
              • 关系会突然改变
              • 机会不是均匀出现
              • 人的能力也不是稳定输出

              所以不要把世界想象成一条连续曲线。

              更现实的理解是：

              世界由一个个不稳定的状态组成，稳定只是阶段性结果。

              # 2. 人不是一个完整统一的自我

              人往往由多个自我组成。

              一个自我想努力，一个自我想逃避；一个自我想长期收益，一个自我想即时满足；一个自我想理性，一个自我已经被情绪接管。

              自控力的关键不是消灭某个自我，而是理解这些相互冲突的部分，并让它们尽量进入同一个方向。

              更好的策略不是：

              • 我必须彻底改变自己
              • 我必须战胜懒惰
              • 我必须压住欲望

              而是：

              • 识别不同自我的需求
              • 降低内部冲突
              • 给每个部分安排合理出口
              • 用系统设计减少硬抗

              # 3. 世界是无限变量

              世界复杂，是因为每个人、每件事、每个环境条件都是变量。

              这些变量彼此连接、相互影响，最终形成一个近乎无限的关系网。

              这意味着：

              • 你无法控制全部变量
              • 你无法预测所有结果
              • 你无法要求世界按自己的想象运行

              想改变结果，就必须改变变量。

              最容易改变的变量通常不是别人，而是自己：

              • 自己的选择
              • 自己的环境
              • 自己的节奏
              • 自己接触的人
              • 自己投入的资源

              改变越多关键变量，生活越可能发生变化。

              # 4. 想象力是一种行为工具

              想象力不只是幻想，也可以用来调节行为。

              当想鼓励自己做某件事时，可以提前想象完成之后的好处和感受。

              当想阻止自己做某件事时，可以提前想象后果、负担和痛苦。

              它适合用在两类场景：

              • 鼓励自己开始
              • 抑制自己冲动

              想象力的价值不在于逃离现实，而在于让身体和情绪提前感受到结果。

              # 5. 接受不可控

              无限变量意味着人必须接受不可控。

              不是所有问题都有答案，不是所有努力都有反馈，不是所有关系都能解释清楚。

              当变量过多时，最重要的不是继续推演，而是回到自己能控制的部分：

              • 今天能做什么
              • 当前能减少什么风险
              • 哪些事情可以暂时不处理
              • 哪些环境可以主动远离

              # 一句话总结

              世界是由无限变量组成的不连续系统，人能做的不是控制一切，而是调整自己这个变量，并让系统朝更好的方向偏移。
